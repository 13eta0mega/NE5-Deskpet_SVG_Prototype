# Mood Critters Studio

강아지, 여우, 곰, 토끼, 고양이의 16가지 감정을 부드럽게 전환하는 React + SVG 데모입니다.

## 실행

```bash
npm ci
npm run dev
```

프로덕션 빌드는 `npm run build`로 생성합니다.

새 PC 설치, 캐릭터·감정 수정 규칙, 모션 레이어와 검수 절차는 [DEVELOPMENT_GUIDE.md](./DEVELOPMENT_GUIDE.md)를 참고하세요.

## 구현된 기능

- 5종 캐릭터 선택
- 편안, 기쁨, 신남, 사랑, 웃음, 뿌듯, 궁금, 놀람, 혼란, 수줍, 슬픔, 걱정, 화남, 시큰둥, 졸림, 울음
- 현재 화면의 중간 포즈에서 다음 감정으로 이어지는 인터럽트 가능한 전환
- 지속적인 호흡과 비주기적 눈 깜빡임
- 몸의 기울기와 좌우 귀 twitch를 합성한 듣기 모션
- 기존 입 형태를 크게 벗어나지 않는 작은 립싱크
- 데스크톱, 태블릿, 모바일 반응형 UI
- 고정 다크 스튜디오 테마와 `prefers-reduced-motion` 지원

## 주요 파일

- `src/main.jsx`: 10개 고정 SVG 파츠, 감정 포즈, 인터럽트 가능한 수치 보간
- `src/styles.css`: 호흡·듣기·립싱크 모션 레이어, 반응형 스튜디오 UI
- `REFERENCE_ANALYSIS.md`: 원본 저장소 분석과 구현 대응 문서
