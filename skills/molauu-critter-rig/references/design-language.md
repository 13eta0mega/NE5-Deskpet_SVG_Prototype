# Design Language

- Work on a 200x200 viewBox.
- Let one soft asymmetric body blob dominate the silhouette.
- Keep feet near y=190-196 so the character feels grounded.
- Use only 10 core parts: legs, ears, body, eyes, mouth, hands.
- Use tiny dark eyes, roughly 3 px radius.
- Use one 3 px round-capped mouth stroke or a tiny filled opening while talking.
- Use hands as simple circles/ellipses and feet as rounded rectangles/ellipses.
- Use 3-4 flat colors: body, feet, paws, face.
- Avoid nose, muzzle, eyebrows, mandatory inner-ear shapes, gradients, shadows, thick outlines, glossy highlights, and detailed fur unless explicitly requested.
- Make emotion readable through eye scale/position, mouth curve, ear pose, hand pose, and whole-body silhouette.
- Do not copy molauu example coordinates, exact silhouettes, or exact palettes.
